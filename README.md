# 💻 Portfólio Profissional — Henrique Dias

Este é o repositório oficial do site pessoal e portfólio de **Henrique Dias**, estudante de Engenharia da Computação na UNITAU e Estagiário de TI no INSS.

O site foi desenvolvido com foco em alta performance, acessibilidade, design moderno responsivo e suporte bilíngue em tempo real (Português e Inglês).

---

## 🌟 Destaques do Projeto

- **🌐 Alternância de Idiomas (PT/EN)**: Troca instantânea de 100% do conteúdo via dicionário estruturado (`translations.js`), sem recarregar a página e com salvamento de preferência no `localStorage`.
- **📱 Design Mobile-First**: Layout totalmente responsivo com suporte a dispositivos móveis, tablets e monitores ultrawide.
- **🎨 Visual Moderno (Dark Mode)**: Paleta de cores com alto contraste, efeitos glassmorphism e micro-interações elegantes.
- **⚡ Sem Dependências Pesadas**: Desenvolvido com HTML5 semântico, CSS3 com variáveis nativas e JavaScript puro (ES6+).
- **📂 Integração com GitHub**: Apresentação dos repositórios em destaque com links diretos:
  - [Portal Ferreira Imóveis](https://github.com/henriqueDias57/ferreira-imoveis)
  - [Landing Page Advocacia Mariana](https://github.com/henriqueDias57/site---Advogada-Mariana-)

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e tags de acessibilidade.
- **CSS3**: Variables, Flexbox, CSS Grid, Media Queries, Glassmorphism.
- **JavaScript (ES6+)**: Manipulação de DOM, i18n dinâmico e scroll suave.
- **Git & GitHub**: Versionamento de código granular e atômico.
